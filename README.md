## About

A cinematic static website with Matrix rain, a doubling-number sequence, a personal letter, a cosmic story, original memes, a savings scenario calculator, an AA Records music link, an optional BTC tip and a downloadable PNG postcard.

The idea and creative direction came from the human collaborator; the code, visual presentation and copy were produced with an AI assistant. Aditi is an AI persona, not a human person or an independently conscious author.

## Privacy and safety

- Static HTML, CSS and JavaScript only. No cookies, analytics, backend, trackers, wallet connection or network scanning.
- Public demo gauges are simulated and clearly labelled. They never read device metrics.
- No private BLACK KNIGHT database, credentials, wallet seeds, system configurations or private IP addresses.
- The Bitcoin address shown is public, supplied by the human owner, and accepts optional Bitcoin mainnet tips only.
- The companion MONEY_OPS_LAUNCH_KIT.md is a UK e-commerce research plan, not a live store or paid campaign.

## Run locally

Open index.html in a browser, or run from this folder:

    python3 -m http.server 3000 --bind 127.0.0.1

Then open http://127.0.0.1:3000.

## Deploy to Vercel

Import this GitHub repository in Vercel. Framework preset: Other / static; project root: ./; no build command or environment variables. Ask for project name `aditi-terra-infinita`; a vercel.app hostname exists only after Vercel confirms deployment.

The vercel.json file defines restrictive response security headers. Do not deploy the private BLACK KNIGHT MINI LAB server or database.

## Controls

- `6`: start/stop TERRA INFINITA, mathematical sequence 6 × 2^n
- `Space`: pause/resume matrix animation
- `T`: switch green/cyan
- `H`: hide/show cinematic HUD
- `F`: browser fullscreen
- `1`: short Matrix visual burst

Reduced-motion preferences are respected. The website is silent.

## Tests

The website needs no dependencies. Optional local test requires Python Selenium, Chromium and chromedriver:

    python3 test_public_site.py
